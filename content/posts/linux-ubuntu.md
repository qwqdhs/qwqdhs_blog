# 一些常用的ubuntu命令（对于我来说）

## 注意事项以及一些提示

- 大小写敏感：`ls` 和 `Ls` 不同，文件名也同样区分大小写
- `Tab` 自动补全：输入命令或路径时按 `Tab` 可自动补全，减少输入错误
- `sudo` 提权：以 `sudo` 开头的命令表示使用管理员（root）权限，需要输入密码，输入过程中密码不会显示
- 获取帮助：大多数命令支持 `--help`（如 `ls --help`）

---

## 1. 文件和目录操作

| 命令 | 功能 | 示例 |
| :--- | :--- | :--- |
| `pwd` | 显示当前工作目录的绝对路径 | `pwd` |
| `ls` | 列出目录内容 | `ls -l`（详细信息）<br>`ls -a`（显示隐藏文件） |
| `cd` | 切换目录 | `cd /home`<br>`cd ..`（上级目录）<br>`cd ~`（用户主目录） |
| `mkdir` | 创建新目录 | `mkdir folder`|
| `touch` | 创建空文件或更新文件时间戳 | `touch file.txt` |
| `cp` | 复制文件或目录 | `cp file1 file2` |
| `mv` | 移动或重命名文件/目录 | `mv old.txt new.txt`（重命名）<br>`mv file.txt /target`（移动） |
| `rm` | 删除文件或目录 | `rm 路径或文件名` |
>[!WARNING]  
>删之前千万要三思啊，删除后东西的不可恢复|

## 3. 软件包管理（APT）

| 命令 | 功能 |
| :--- | :--- |
| `sudo apt update` | 更新软件源列表 |
| `sudo apt upgrade` | 升级所有已安装的软件包 |
| `sudo apt install <软件名>` | 安装指定软件 |
| `sudo apt remove <软件名>` | 卸载软件（保留配置文件） |
| `sudo apt purge <软件名>` | 彻底卸载（删除配置文件） |
